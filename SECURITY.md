# Security policy

Report a vulnerability **privately**, through GitHub: the **Security** tab of this
repository, then **Report a vulnerability**. Please do not open a public issue.

We acknowledge reports as quickly as we can, fix them in a new npm version, and publish the
advisory once users have had the time to update.

In scope: this CLI and the cryptography it ships (`lib/crypto/`). The limits the README
states openly ("What it does not protect against") are known, and not vulnerabilities by
themselves — a way to go beyond them is.
